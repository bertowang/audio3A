§A.1全书符号与公式速查

按「信号模型 → 自适应 → 指标 → 掩码与重建 → 电平」排列；公式是便于记忆的教学写法，工程实现请以 tools/dsp.py 与对应标准原文为准。

信号模型：y[n] = d[n] + (h * x)[n] + v[n] = d[n] + Σ_k h[k] x[n−k] + v[n]

NLMS：e[n] = d[n] − wᵀ[n] x[n]　，w[n+1] = w[n] + μ e[n] x[n] / (‖x[n]‖² + δ)

ERLE = 10 log₁₀( Σ e²[n] / Σ r²[n] )　，segSNR = mean_t 10 log₁₀( Σ d² / Σ (d−d̂)² )

SI-SDR：α = ⟨ŝ,s⟩ / ‖s‖²　，SI-SDR = 10 log₁₀( ‖α s‖² / ‖ŝ − α s‖² )

Wiener / IRM 增益：G[t,k] = ξ/(1+ξ) ≈ |S[t,k]|² / ( |S[t,k]|² + |N[t,k]|² )

WOLA 重建：x̂[n] = Σ_f X̂_f[n] w[n−fH] / Σ_f w²[n−fH]　，H = N/2

量化 SNR ≈ 6.02 B + 1.76 dB　，LUFS 为 K 加权加门控的响度（本书 lufs_approx 是教学近似）

§A.4实验环境与复现约定

  1. 运行环境：Python 3 标准库即可，不需要 numpy / scipy / torch / matplotlib / librosa / soundfile。
  2. 随机数：PREAMBLE 固定 random.seed(7)，实验内再用 rng = random.Random(7)，保证逐行可复算。
  3. 采样率：SAMPLE_RATE = 16000，WAV 为 16-bit 单声道 PCM，由 write_wav() 写出。
  4. 产物：每个脚本在章节根目录写 fig/*.svg（Chart().save() 或 heatmap()）与 audio/*.wav；文件名带本章编号前缀以避免冲突。
  5. 单章运行：python3 part6/31-capstone/code/31-capstone.py；语法自检：python3 -m py_compile tools/chapters_30_A.py。
  6. 批量运行：先由生成器把 demos 的 code 落到各章 code/*.py，再逐个 python3 <路径>；页面代码块与 code 文件由同一份数据同步，不要手改生成的 HTML。
可核对性

每个实验都打印可手算核对的数值（ERLE、SNR、SI-SDR、LUFS、WAV 帧数与字节数），并声明 fig / audio 的文件名；运行时间控制在几秒内。

边界

全部语音、噪声与 RIR 均为代码合成信号，不是真实录音，也不是任何厂商产品的性能数据；教学实现不能直接用于生产环境。
