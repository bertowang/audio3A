本书的主张

3A 是一套可验证的流式估计系统：房间是 FIR 滤波器，AEC 是在线系统辨识，ANS 是谱上的统计估计，AGC 是反馈控制器；下卷把同一批估计器换成网络，但链路结构、因果约束与评价指标完全不变。

每章学习闭环固定为四步：读模型 → 跑代码 → 改参数 → 写结论；脚本用固定随机种子合成全部信号，打印可手算核对的数值，并画出可提交的 SVG 图与 WAV 样本。

实验边界说明：本书为教学材料。全部语音、噪声与房间冲激响应都是代码合成的信号，不是真实录音，也不是任何厂商产品的性能数据；脚本中的 FFT、自适应滤波、谱减、小型网络等均为可读的教学实现，用于说明机制与量级，不能直接用于生产环境。书中提及 ffmpeg、WebRTC、SpeexDSP、RNNoise 等工具的版本与能力请以各自的官方文档与本机 ffmpeg -filters / ffmpeg -version 实际输出为准；本书与这些项目无从属关系，也不构成产品推荐。

运行 Python 实验（30 秒）

  1. 需要 Python 3.8+，不需要安装任何第三方包：实验只用 math、random、statistics、wave 等标准库，以及仓库内的 tools/dsp.py（纯标准库 DSP）与 tools/chart.py（纯标准库 SVG 绘图）。
  2. 直接运行某一章脚本：python3 part0/00-three-a/code/00-three-a.py；或从页面代码块右上角「复制」。
  3. 批量运行并生成全书插图与试听样本：./tools/run_python.sh；只跑某几个：./tools/run_python.sh part1/05-adaptive-filter/code/05-nlms.py。
  4. 页面代码块与磁盘 code/*.py 由 tools/extract_code.py 自动同步，永远一致。
给程序员的代码契约
  • 1. 只用 Python 3 标准库 + 仓库内 tools/dsp.py 与 tools/chart.py，无第三方包；
  • 2. 自包含：语音 / 噪声 / 房间冲激响应由代码合成，不联网、不读外部音频文件；
  • 3. random.seed(7) 固定随机数，采样率统一 16 kHz，可调量集中在「参数区」；
  • 4. 打印可手算核对的数值（ERLE、SNR、SI-SDR、收敛迭代数等）；
  • 5. 生成 fig/*.svg 矢量图与 audio/*.wav 试听样本，页面内可看波形、可听效果；
  • 6. 页面代码块与 code/*.py 由 tools/extract_code.py 自动同步。

为什么不用 numpy / torch / matplotlib？教材要展示的是算法本身与「图、声音是怎么生成的」。下卷涉及真实训练时，各章会给出 PyTorch / ONNX Runtime / 开源工程的进阶入口；附录 A.6 给出手写实现与工业库的对照表，学完之后应能无缝切换。

本机没有 ffmpeg 也能读完全书：ffmpeg / WebRTC 命令片段是可选真机实验，一律要求先用 ffmpeg -filters 与 ffmpeg -version 自查，本书不假定任何特定版本具备某项能力。
